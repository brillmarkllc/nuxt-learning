# 04. Repositories

Course section: 1: Introduction

A **repository** is a project stored with a history of its changes. Git records that history; GitHub is one service where repositories can be shared. A **branch** holds a separate line of changes, such as a finished example.

The existing lesson resources do not provide a verified source-repository address or branch list. That is a source gap: there is no confirmed project to download here. Do not substitute a random repository and assume it matches these notes.

You can still follow the practical examples by creating a fresh Nuxt app in topic 06. Nuxt's installation page also links to an official starter you can try in your browser.

**Additional example:** If you later receive reference files, keep them in a separate folder called `reference-app`, alongside your own `practice-app`. Compare a single file at a time, including its location. A Nuxt 3 example may put pages in `pages/`; the Nuxt 4 examples here use `app/pages/`.

Before running a downloaded project, read its README for setup instructions. A repository may need packages, private settings, or an external service that a fresh starter does not need.
