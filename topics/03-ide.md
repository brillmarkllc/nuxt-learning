# 03. IDE

Course section: 1: Introduction

An **editor** is where you create and change code files. An **IDE** is an editor with extra tools, such as a terminal and error checks. Nuxt does not require a particular editor.

The Nuxt installation guide recommends Visual Studio Code with the Vue extension, or WebStorm. Choose one you find comfortable.

## Set up Visual Studio Code

1. Install [Visual Studio Code](https://code.visualstudio.com/).
2. Open its Extensions panel and install **Vue - Official**. Its identifier is `Vue.volar`; it helps the editor understand `.vue` files.
3. After creating a project in topic 06, use **File → Open Folder** to open the whole project folder.
4. Choose **Terminal → New Terminal** to run commands without leaving the editor.

**Additional example:** Once the project exists, run `npm run dev` in that terminal. Keep it open while you edit. The terminal prints the local address to visit in your browser.

An editor extension helps you write code; it does not install packages into your website. Tailwind or other styling tools can wait until a project actually uses them.
